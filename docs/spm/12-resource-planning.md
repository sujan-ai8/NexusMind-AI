# Software Project Management: 12. Resource Planning & Allocation

## 1. Human Resources & Allocation Matrix
| Role | Core Responsibilities | Phase 1 Allocation | Phase 2–6 Allocation |
|---|---|---|---|
| **Solution Architect** | System topology, monorepo design, DB schemas, security model | 100% | 25% |
| **Frontend Engineer** | React, Tailwind, Recharts, Responsive UI, State management | 100% | 50% |
| **Backend Engineer** | FastAPI endpoints, services, repositories, Alembic migrations | 100% | 50% |
| **DevOps Engineer** | Docker, Docker Compose, CI/CD pipelines, AWS setup | 75% | 75% |
| **Data & ML Engineer** | Feature stores, model training, RL environment, GenAI integration | 25% (Foundations) | 100% |

---

## 2. Infrastructure & Tooling Resources
- **Development Workstations:** Multi-core x86_64, minimum 16 GB RAM, 256 GB SSD.
- **Runtimes & Frameworks:** Node.js 20+, Python 3.11+, PostgreSQL 16, Redis 7, Docker Desktop.
- **Version Control & CI:** Git, GitHub Actions, Docker Registry.
- **Cloud Infrastructure (Phase 6):** AWS Free Tier / Academy (EC2 t3.medium, S3, RDS Aurora PostgreSQL).
